检查本地**已安装的第三方 Python 包是否过时**，有**最简单命令**、**专业工具**两种方法，我直接给你最实用、最常用的方案👇

# 一、最简单：一行命令查看所有过时包（无需安装）
直接在 **终端 / CMD** 运行：
```bash
pip list --outdated
```

### 它会输出：
```
Package    Version  Latest   Type
---------- -------- -------- -----
numpy      1.21.0   1.26.4   wheel
pandas     1.4.2    2.2.1    wheel
requests   2.25.1   2.31.0   wheel
```

- **Version**：你本地现在的版本
- **Latest**：官方最新版本

**这是 Python 自带功能，最稳、最快。**

---

# 二、一键升级所有过时包（可选）
如果你想**一次性把所有包升到最新**：
```bash
pip freeze | grep -v "^-e" | cut -d = -f 1 | xargs pip install -U
```

Windows CMD 用这个：
```cmd
for /f "tokens=1 delims==" %i in ('pip freeze') do pip install -U %i
```

---

# 三、更专业、更美观的工具：pip-review（推荐）
这个工具能**列出、选择升级、一键升级**，非常好用。

## 1. 安装
```bash
pip install pip-review
```

## 2. 查看所有可更新包
```bash
pip-review
```

## 3. 交互式选择更新（推荐）
```bash
pip-review --interactive
```

它会一个一个问你：
`Update numpy (1.21.0 → 1.26.4)? [Y/n]`

你按 Y 或 N 即可。

## 4. 自动全部更新
```bash
pip-review --auto
```

---

# 四、检查单个包是否最新
```bash
pip show 包名
```
然后去官网对比版本，或直接：
```bash
pip install 包名==none
```
会提示你最新版本。

---

# 总结（最实用）
- **查看哪些包过时**：`pip list --outdated`
- **美观+可选择升级**：`pip-review --interactive`
- **一键全部升级**：`pip-review --auto`
