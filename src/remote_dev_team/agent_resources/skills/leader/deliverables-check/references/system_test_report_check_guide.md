# 系统测试阶段交付物检查指南

## 一、文档元数据（YAML Frontmatter）

- [ ] 必须包含以下字段：
  ```yaml
  ---
  title: 系统测试报告名称
  author: Eva
  date: YYYY-MM-DD
  version: x.y.z
  state: 评审中/已通过
  ---
  ```

## 二、测试概况

### 2.1 测试范围

- [ ] 是否说明测试了哪些功能模块
- [ ] 是否说明未测试的功能及原因

### 2.2 测试环境说明

- [ ] 是否说明操作系统、浏览器（若有）、Python 版本
- [ ] 是否说明其他相关环境信息

## 三、需求追溯矩阵

- [ ] 是否建立需求 - 测试映射，确保所有P0/P1需求都被测试：

    需求编号 | 需求描述 | 优先级 | 测试内容 | 测试结果

- [ ] P0/P1 功能在表中是否都有对应测试内容和结果（通过/失败）

## 四、发布建议

- [ ] 明确给出是否可以发布的建议：

    **可以通过**：所有 P0 功能测试通过
    
    **需要修复**：存在 P0 功能失败，列出必须修复的问题清单

---

**评审重点：**

- 是否为每个P0、P1功能设计了测试内容
- 需求追溯矩阵中的测试结果是否如实记录（通过/失败）
- 发布建议是否基于事实和数据
- 是否专注于系统测试，未涉及单元测试或集成测试

**不通过反馈模板：**

```
【存在问题】
1. ...
2. ...

【修改要求】
1. ...
2. ...
```
